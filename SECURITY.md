# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

As the project is pre-1.0, only the latest released version receives security fixes.

## Reporting a vulnerability

Please report security vulnerabilities **privately**. Do not open a public issue for security
problems.

- Email: **matheuszwilkdev@gmail.com**
- Include: a description of the issue, steps to reproduce, affected version(s), and any potential
  impact you have identified.

You can expect an initial acknowledgement within **5 business days**. We will keep you informed of
the progress toward a fix and coordinate a disclosure timeline with you.

Thank you for helping keep Visus Desktop and its users safe.
